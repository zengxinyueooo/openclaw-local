## 🌱 成长收获

### 1. 子 Agent 通信机制
- `mode: "run"`：一次性任务，结果在 session 里，需主动取或明确要求通知
- `mode: "session"`：持久 session，可双向通信
- 子 Agent 没有主动发消息的能力，除非 task 里明确指示用 message 工具

### 2. mc-code-agent skill 使用
- 必须用 `exec(pty=true, background=true)` 启动 `mc --code`
- 使用 `process` 工具进行交互（log/send-keys/paste/poll/kill）
- 流程：启动 → 确认信任界面 → 按 Enter → 确认主界面 → paste 任务 → 轮询等待 → kill

### 3. AGENTS.md 管理
- 主 Agent 和小橙的 AGENTS.md 都要更新
- 技能变更时要同步更新文档
- 要给具体的工具调用示例，不能只描述
