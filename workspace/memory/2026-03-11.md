## 🕳️ 踩坑记录

### 坑一：Git 仓库嵌套问题
- **现象**：在 `~/.openclaw/` 初始化 git 后，`git add` 报错 `workspace/ does not have a commit checked out`
- **原因**：`~/.openclaw/workspace/` 本身已经是一个独立的 git 仓库，不能嵌套
- **解决**：删除 `~/.openclaw/.git`，改用 `workspace/` 作为备份根目录
- **教训**：先检查子目录是否已经是 git 仓库，避免嵌套

### 坑二：远程仓库非空导致推送失败
- **现象**：首次 `git push` 报错 `failed to push some refs`
- **原因**：GitHub 仓库创建时带了 README，本地历史与远程不一致
- **解决**：先 `git pull origin main --rebase` 同步远程，再推送
- **教训**：新仓库如果带初始化文件，先拉取再推送

### 坑三：变更统计命令不兼容
- **现象**：`git diff --stat` 解析插入/删除行数时返回空
- **原因**：不同 git 版本的输出格式有差异
- **解决**：改用 `tail -1` 取最后一行统计，增加默认值处理
- **教训**：脚本要考虑跨平台兼容性，重要变量给默认值
