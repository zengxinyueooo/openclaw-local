## 🕳️ 踩坑记录

### 坑一：daxiang 通道 SSO 认证失败
- **现象**：消息发送失败，提示 `Unknown target "xxx" for daxiang`
- **原因**：缺少 SSO token，未完成美团认证
- **解决**：运行 `npm run generate-sso`，浏览器登录后获取 token
- **教训**：插件启用后必须完成认证才能使用

### 坑二：API Key 配置位置混淆
- **现象**：不确定 Tavily API Key 保存在哪里
- **原因**：之前提过但忘记保存位置
- **解决**：明确保存到两个位置（skill/.env 和 openclaw.json）
- **教训**：配置信息要记录清楚位置

### 坑三：系统 cron vs OpenClaw cron 混淆
- **现象**：面板不显示定时任务
- **原因**：系统 crontab 和 OpenClaw cron 是两个系统
- **解决**：删除系统 cron，改用 `openclaw cron add` 创建 agent 任务
- **教训**：统一使用 OpenClaw 原生功能，便于管理和监控

### 坑四：OpenClaw cron 参数不熟悉
- **现象**：`--schedule` 和 `--command` 参数报错
- **原因**：OpenClaw cron 设计为调度 agent，不是执行 shell
- **解决**：使用 `--agent`、`--message`、`--cron` 参数
- **教训**：先查看 help 文档，了解工具设计意图
