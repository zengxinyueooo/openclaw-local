## 🕳️ 踩坑记录（深夜）

### 坑十：subagent 的 Tavily API Key 找不到
- **现象**：小葡执行 skill 时提示 `TAVILY_API_KEY` 未配置
- **原因**：skill 脚本从环境变量读取，没有自动加载 .env 文件
- **解决**：修改 `search.mjs` 脚本，添加自动读取 `.env` 文件的功能
- **教训**：skill 脚本要考虑 .env 加载，不能依赖外部 source

### 坑十一：subagent session 不自动清理
- **现象**：已完成的 subagent 任务在列表里保留超过30分钟（甚至1小时+）
- **原因**：`sessions_spawn` 默认 `cleanup: "keep"`，且 `archiveAtMs` 是1小时不是30分钟
- **解决**：派任务时加 `cleanup: "delete"` 参数，或手动运行 `openclaw sessions cleanup`
- **教训**：注意 cleanup 参数，避免 session 堆积

### 坑十二：self-improvement skill 需要手动触发
- **现象**：错误发生后没有自动记录到 PITFALLS.md
- **原因**：没有配置 hook，skill 完全依赖手动调用
- **解决**：配置 `~/.openclaw/hooks/self-improvement/` 自动触发，并和 PITFALLS.md 联动
- **教训**：重要 workflow 要配置自动化，不能依赖记忆

- **现象**：面板不显示定时任务

- **解决**：删除系统 cron，改用 `openclaw cron add` 创建 agent 任务

- **现象**：`--schedule` 和 `--command` 参数报错

- **解决**：使用 `--agent`、`--message`、`--cron` 参数
- **教训**：先查看 help 文档，了解工具设计意图
