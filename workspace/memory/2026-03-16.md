## 技术收获

### 子Agent调用规范
```python
# 普通子Agent（小橙/小葡/小莓）
sessions_spawn(
    agentId="coder|researcher|xiaomei",
    task="任务描述",
    mode="run"
)

# ACP编码Agent（Claude Code）
sessions_spawn(
    runtime="acp",
    agentId="coder",
    task="任务描述",
    mode="run"
)
```
